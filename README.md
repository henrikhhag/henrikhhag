### 🏠 Featured project — henami

**A personal dashboard for budgeting, calendar, training, nutrition and travel — on web and iOS.**

[![React](https://img.shields.io/badge/React-19-21262d?style=flat-square&logo=react&logoColor=white)](https://react.dev)
[![Expo](https://img.shields.io/badge/Expo-SDK%2054-21262d?style=flat-square&logo=expo&logoColor=white)](https://expo.dev)
[![Supabase](https://img.shields.io/badge/Supabase-Postgres%20%2B%20Auth-21262d?style=flat-square&logo=supabase&logoColor=white)](https://supabase.com)
[![Vercel](https://img.shields.io/badge/Vercel-deployed-21262d?style=flat-square&logo=vercel&logoColor=white)](https://vercel.com)

![henami in action](https://raw.githubusercontent.com/henrikhhag/henami-showcase/main/docs/screenshots/hero.gif)

</div>

henami brings together budgeting, calendar, training log, meal diary and a travel map into one app — built from scratch, one shared Supabase backend, two clients:

- **Web** — React 19 + Vite, deployed on Vercel
- **iOS** — React Native + Expo, feature-complete with the web app, currently in TestFlight ahead of an App Store release
