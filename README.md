### 🏠 Featured project — henami

**A personal dashboard for budgeting, calendar, training, nutrition and travel — on web and iOS.**

henami brings together budgeting, calendar, training log, meal diary and a travel map into one app — built from scratch, one shared Supabase backend, two clients:

- **Web** — React 19 + Vite, deployed on Vercel
- **iOS** — React Native + Expo, feature-complete with the web app, currently in TestFlight ahead of an App Store release

**📎 [See the full showcase — screenshots, architecture, and selected code](https://github.com/henrikhhag/henami-showcase)** *(source is private; the showcase repo has the details)*
